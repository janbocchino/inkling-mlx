# Historical Word report builders

These are the scripts that produced the earlier baseline report and next-series plan. Account/user locations in their prose were redacted for publication; numerical experiment code elsewhere remains unchanged.

They require `python-docx` and the original workspace's `outputs/` layout. They are retained as provenance, not supported entry points in this repository. They also reproduce old descriptions corrected by `docs/REPORT.md`. The current consolidated deliverable is Markdown; no Word render is needed to read or update it.
